# 值星/公差輪值表產生器 (mess-duty-roster-for-army)

一個純前端的排班小工具，用來產生軍中站哨、公差、值星等輪值表。不需要伺服器或資料庫，開啟 `index.html` 即可使用，資料會自動儲存在瀏覽器的 `localStorage` 中。

## 功能

- 新增/移除人員名單
- 每位人員可設定「排除日期」（請假、不可排班的日子）
- 設定排班區間（起始日期～結束日期）與每日需求人數
- 依「累計值班次數最少者優先」的規則自動輪替，讓值班次數盡量平均
- 產生班表後可匯出 CSV 或直接列印
- 名單與設定會自動存在瀏覽器本機，重新整理頁面不會遺失

## 使用方式

直接用瀏覽器開啟 `index.html`，或用任何靜態網頁伺服器（例如 `npx serve .`）啟動後瀏覽。
