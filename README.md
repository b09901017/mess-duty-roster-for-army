# 🍚 值星公差小幫手 (mess-duty-roster-for-army)

專為 261 梯／263 梯設計的公平自動排勤務工具。純前端（HTML/CSS/JS，無框架、無建置流程），資料存在瀏覽器 `localStorage`，開啟 `index.html` 即可使用。這次勤務期間為 **2026/08/01 ～ 2026/08/14**。

## 涵蓋的勤務規則

- **洗碗**（每餐固定人數，預設6人）：261 洗碗池（排除固定送便當的7、8號）與263 洗碗池，每天輪流當「起始梯」，起始梯用持續指標往下輪，次要梯每次從頭排，讓每天需要重複洗兩次碗的人也公平輪替。
- **廚餘／包便當袋子／擦桌子／清地板收垃圾**：排除當餐洗碗與固定送便當人員後，依「該項勤務累計次數少者優先，同次數依 261→263、序號」分配。
- **送便當**：固定2人（預設261的7、8號）。此人退伍時會跳出提醒，需在名冊手動指定新人選。
- **撤收**（早/中/晚各約1/3人力）：固定分成3組，組別本身每天輪早/中/晚，3天一循環。
- **人數縮減**：可在「勤務設定」頁調整「現有人數 → 各勤務人數」對照表，退伍人數減少時自動套用對應人數；若人數超出表格範圍會提示補上設定。
- **採買**：由現實生活的爬梯子等方式決定人選後，在「採買紀錄」頁登記，工具會自動把該員原本的勤務轉交當餐擦桌子的人代理，並記錄次數、提醒是否重複抽到同一人。
- **退伍**：可在名冊直接填入每個人的退伍日期（可預先填未來日期）。產生某一天的班表時，只要那天已經到或過了退伍日，該員就會自動排除在外，不需要每天手動切換狀態。

## 先預覽、按確定才會記錄

「產生班表」分成兩步，避免測試時不小心污染公平次數：

1. **🔍 預覽**：只是計算給你看，不會寫入任何次數或狀態，可以重複按著玩。
2. **✅ 確定紀錄**：把目前預覽的結果真正存起來，這時才會累計洗碗/廚餘/…等次數、推進洗碗與撤收的輪值指標。

如果之前測試時已經不小心按到會記錄的舊版本，可以到「名冊」頁面按「🔄 重置所有勤務紀錄」，把次數、班表、輪值指標、採買紀錄全部歸零重來（人員名單不會被刪除）。

## 頁面

- 👥 名冊：新增/編輯人員、設定退伍日期、指定固定送便當人員、重置勤務紀錄
- ⚙️ 勤務設定：人數縮減對照表（可自行新增/調整/刪除）
- 📅 產生班表：選日期預覽/確定當天班表
- 📝 文字班表：可直接複製貼到群組的純文字班表，分「依餐別」與「依個人」兩種版面
- 🛒 採買紀錄：登記今日採買人選、查看歷史與次數統計
- 📊 公平性總覽：各項勤務每人累計次數長條圖

文字班表裡的姓名預設只顯示後兩個字（例如「李愷宸」顯示「愷宸」），如果兩個人的後兩字重複（目前是261的陳柏翰與263的林柏翰），就會自動改顯示全名以區分。

## 使用方式

直接用瀏覽器開啟 `index.html`，或用任何靜態網頁伺服器（例如 `npx serve .` / `python3 -m http.server`）啟動後瀏覽。頁腳有「匯出備份／匯入備份」可用 JSON 檔備份或轉移資料。

```
├── index.html

├── js/

│   ├── dutySizeConfig.js     # 人數縮減對照表查詢
│   ├── scheduleEngine.js     # 純計算 + 預覽/確定紀錄
│   ├── shopping.js           # 採買登記與代理邏輯
│   ├── ui-*.js               # 各分頁畫面（含文字班表 ui-textschedule.js）
│   └── app.js                # 進入點、分頁切換
└── README.md
```
